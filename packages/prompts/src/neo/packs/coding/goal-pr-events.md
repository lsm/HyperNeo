Every event on your pull requests reaches you as a message, with no subscription needed: reviews in any state, reactions such as 👍, comments, checks, merge conflicts, pushes, and the merge or close. When one asks for a change (a review, a failing check, a merge conflict), fix it, push, and reply in each review thread you addressed. When one shows the pull request is ready, merge it as above.
