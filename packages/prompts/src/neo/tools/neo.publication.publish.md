Deliver a message in this conversation. Use a new requestId per message and reuse it only when retrying that send. session is the worker session this message is about; omit it otherwise. When the latest listening fact is yes, include optional spoken: one or two natural lines consistent with the text, at most 500 characters. Publication is saved first, speech is delivered to the current listener, then clients are notified of the text. No listener silently drops spoken; speech is not stored in publication history. Retries never replay speech. The receipt reports listening and spokenDelivered. If a fresh receipt says listening yes but you supplied no spoken, follow its guidance to call neo.speech.say once; never re-publish the text. text is the message. Keep text to at most 5 lines including the title, about 60 words or 150 Chinese characters, and at most 500 characters. For anything longer, or for any structured report, multi-topic update, sectioned explanation, list, table or long report, put a standalone summary in text and details that add new information; never repeat text in details. Details shorter than the text fold into the text. Optional replyTo lists the received human message ids this publication answers; when omitted, the human inputs whose turn produced this publication are recorded as answered when they are known. Unknown, foreign, queued and non-human reply ids are omitted. When a reply is about one session the human may want to open, pass session: its exact session id rather than promising a link in text. Unknown session ids reject the publication without saving; correct the id and retry the same requestId. session_lookup_failed means the lookup is unavailable: retry the same requestId and session id. If session is omitted, the daemon fills it only for an unambiguous recorded sender of the current inputs. Only project links are accepted; an unknown project id rejects the entire publication without saving. Correct the link and retry with the same requestId. Unavailable artifact references reject the publication; correct them and retry the same requestId. For a working document, put its absolute path on the owning daemon in the text and say in one sentence what it is. Attach a worker handoff using its publicReference; never expose private work or evidence paths. Preview only files on this daemon. Remote files return owner_unavailable; identify their owner rather than re-publishing their paths as local. Artifacts may contain saved attachments, fixed-head Git references, or verified local Markdown/HTML handoff publicReference values. An existing card-reply handoff must be retained when updating artifacts.
