---
id: neo.todo.done
---
Mark any live todo done, started or not, with an optional reason. Use it when the work is finished or the step is no longer needed: a plan changes, and a step nobody needs is simply done. A missing reason or unmet check does not refuse it. An unanswered card linked to this todo refuses completion with the question ID; wait for the human to answer it. Its session stops if it is running, unless the todo only follows a session the human tracked; the todos that waited for it start. To cancel work so that what waits on it does not start, use neo.todo.remove.
