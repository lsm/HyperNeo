---
id: neo.todo.done
---
Mark any live todo done, started or not, with an optional reason. Use it when the work is finished or the step is no longer needed: a plan changes, and a step nobody needs is simply done. Nothing refuses it: not a missing reason, an unmet check or an unanswered card. Its session stops if it is running, unless the todo only follows a session the human tracked; a card asked about this todo is retired, and the todos that waited for it start. To cancel work so that what waits on it does not start, use neo.todo.remove.
