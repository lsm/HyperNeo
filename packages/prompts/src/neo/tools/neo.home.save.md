id: neo.home.save
---
Save one curated document and commit locally. With a configured origin/upstream, fetches and rebases in an isolated worktree before a protected fast-forward, then writes and pushes. Network steps are noninteractive and stop after 30 seconds. A conflict leaves the original home untouched and returns questionId for one human choice with a full-version document; answering alone does not apply that choice; conflictQuestionId applies a human Keep local/Use remote answer from its recorded path and version to one regular conflicting document using exact selected bytes and a merge preserving both histories. Multi-file, deletion and Review together choices require further review. Direction/mandate still need a separate exact-path/SHA questionId; the version choice never bypasses it. RPC remote publication uses a revision lease; push_failed retains the named local commit for retry. Allows unrelated staged, edited and untracked home files; commits only the requested document and any confirmed decision log. Refuses credential-like content when origin is configured, and internal/ignored paths. Direction and mandate require questionId: a matching human yes on a root-Neo question bound to the exact path and content SHA-256. Appends the confirmed decision and commits both files with Neo-Confirmed-By. Root Neo or the local user only; Neo owns its home documents and can edit them with file tools; this RPC commits with attested decisions while Neo owns its unsandboxed Bash writes. This operation retains a human-facing RPC for confirmed mandate/direction receipts with a decision log; direct edits do not attest human approval. Credential publication checks cover these RPC paths; direct remote Git commands follow the prompt rule against publishing credentials and is not constrained by this RPC gate.
