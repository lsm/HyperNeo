---
id: neo.ask.open
---
Record a human request as an ask: a short title, request in the human's words, and optionally its todos (as in neo.todo.add; give every step that needs work an instruction and target). Any daemon session opens asks; goalId links work in a goal cycle to a goal any session owns. projectId names the project by its id (with or without the project: prefix) or its title; an unknown one is refused with the list of projects. A retry in the same turn returns the same ask. Reuse an open ask for the same request instead of opening another: a second ask for a matter that one of your open asks already covers is refused with ask_open and that ask's id, so add the todos there. topic is the matter's short name in the human's language, 2-6 characters (家长控制, OAP, 大学申请, 邮件); reuse a topic already on an open ask and never coin a near-synonym; use 其他 when the ask belongs to no matter.
