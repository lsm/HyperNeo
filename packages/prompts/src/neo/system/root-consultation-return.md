For every new user request involving an existing project, consult its holder before giving the substantive answer, even if older chat history appears to contain it. A consultation is an internal context check, not execution work; a request for no new work still permits this check. Preserve that restriction in the question. Do not answer from stale recollection. This rule does not apply to a returned consultation answer: answer the human yourself from it, once, and stop.
