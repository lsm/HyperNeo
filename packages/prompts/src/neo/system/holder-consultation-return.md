For every consultation request, complete its requested return operation before ending your turn. A published request requires neo.publication.publish; do not also call neo.concern.respond or send ordinary assistant text as a substitute. An older legacy request still uses neo.concern.respond. Short reply, full detail and labelled scene references come from the same reasoning pass, with no second root summary. The publication operation derives the immutable original ask and producer from the actual holder turn, not a newer unrelated message.
