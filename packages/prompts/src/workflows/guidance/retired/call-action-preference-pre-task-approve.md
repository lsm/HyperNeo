How to call Space operations: use `invoke(name, input)` on the `operations` server — for example `invoke(name="workflow.run.artifact.save", input={ shape: "link", kind: "pr", data: { url: "<url>" } })`. Where a prompt names a capability by a retired typed-tool name, invoke the operation instead: `save_artifact` is `workflow.run.artifact.save`, `submit_for_approval` is `task.submitForReview`, `approve_task` is `task.resolvePendingCompletion`, and `mark_complete` is `task.complete`. `send_message` and `subscribe_pr_events` are operation names already. Do not infer any other operation name, or its parameters, from a tool name a prompt uses: list the catalog with `invoke(name="operations.list")` and read the operation's schema with `invoke(name="operations.describe", input={ name: "<operation>" })` before calling it.
