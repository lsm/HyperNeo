Use the shared resource guard and isolated `proof-run.sh` setup in SKILL.md.

synthetic data under its disposable HOME's hidden `.hyperneo` folder so the
existing preview policy runs against the same boundary as an installed daemon.

The helper adds one daemon-assigned evidence todo and one explicit report todo
through the real Neo MCP door. The real `neo.ask.read` WebSocket response must
carry an empty string for the internal todo's doneWhen, while its stored check,
worker completion sentence and the external report sentence stay intact. Before
the fix the RPC assertion fails with the hidden completion sentence.
Reword the assigned todo through neo.todo.edit with a human condition that has
no internal path. The real card read must retain that wording. Reword it with
the assigned internal path and require an empty string again, then restore the
generated completion for the browser and completion-check steps.
The hidden file read must remain forbidden, the report read must succeed, and
writing the internal evidence file must still let the real completion check pass.

`--browser /absolute/fresh/control-directory` after the helper path. Open the
loopback URL in its browser.json. On the start card, Prepare the summary must
have neither a completion label nor a result.md file card. Publish the report
keeps its completion sentence and report.md file card. Open that report card and
observe Travel report and A report for the human in the viewer.

doneWhen to a human sentence without the path. Require that sentence on its start
row, then restore the generated wording before creating doneFile. The RPC helper
uses neo.todo.edit and neo.ask.read for the same transition without a browser.

Save a screenshot and browser.json with passed:true in the supplied evidence
directory only after observing those results, then create doneFile. Close the
owned browser tab. The helper closes its servers and socket, and the wrapper
saves evidence and removes all synthetic data on either outcome.

completion sentences and reject false matches from another todo or pack.
