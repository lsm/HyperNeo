# Shared delegation preferences

Follow SKILL.md for the pinned runtime, resource check and fresh synthetic HOME.
Run from the checkout root, retaining evidence outside the worktree.

```sh
bash .claude/skills/verify/proof-run.sh /absolute/fresh/evidence-directory \
  .claude/skills/verify/delegation-pack.ts verify
```

The helper boots the real isolated daemon on a free port, without providers or
model turns. It selects an explicit coding-only pack list, reads conservative
delegation defaults through Neo MCP, and starts a coding todo through the real
core operations and runner. Its deliberately long instruction is cropped to the
existing message limit while retaining shared delegation guidance and data.
An authenticated human RPC changes payment to
fillStop. Neo reads the new value, and the next coding worker delivery contains
it. An agent write is refused. Both todo bindings and input journals are checked.

Only work.start is replaced with a synthetic driver that captures the actual
dispatch text and records its receipt. This proves shared guidance construction
and runtime wiring, not a model's compliance with instructions or a native
worker launch. observed.json retains RPC/MCP replies and both delivery texts.
The helper closes its connection and daemon in finally; the wrapper preserves
logs and removes its synthetic data. Require run-status.json exitCode 0.

For the real SDK prompt-delivery seam, run the existing isolated fixture too.

```sh
bash .claude/skills/verify/neo-unsandboxed-sdk.sh /absolute/fresh/sdk-evidence-directory
```

Both store and daemon-gh variants must pass. Their expected coordinator prompt
uses the delegation pack instance's current data, rather than its static catalog
brief. The local scripted model observes that prompt, reads and uses tools,
resumes the session and publishes a reply. This verifies SDK prompt delivery,
not a generative model's adherence to delegation preferences.
