# New work needs the human's yes

Use the shared isolated setup:

```sh
TMPDIR=/private/tmp bash .claude/skills/verify/proof-run.sh /absolute/fresh/evidence-directory .claude/skills/verify/new-work-source.ts
```

The real Neo MCP calls refuse an untracked start, a proposal with todos and a
todo on an unapproved proposal. The human snapshot shows the approval card; a
human RPC approval permits a todo and a refusal drops a second ask. A settled
proposal retry returns its ask_settled record without adding work. The evidence
records the replies and snapshot. An oversized proposal is refused, and a chat
reply leaves the approval or relayed-session card open until the human presses a
decision button.
For each remote worker adapter, a recorded message permits a notice past the
source gate; an unrelated sender is refused. The synthetic remote is unavailable,
so this checks admission and does not claim delivery.
