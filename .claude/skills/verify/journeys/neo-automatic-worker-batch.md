# Automatic Neo wakes expose their worker batches

Use the shared in-process RPC setup in SKILL.md and the ephemeral-model setup in
neo-human-worker-batch.md. Run neo-human-batch.ts with a fresh run directory and
--automatic. It owns the daemon, model listener, synthetic HOME/data and GitHub
stub; no live service or existing port is reused.

The small mixed text/image batch is released by an explicit blocked report. The
oversized batch is released by advancing the timer cutoff through the daemon's
DB writer, without waiting fifteen minutes of wall-clock time. Both deliveries
finish before the helper sends the later whitespace-sensitive human message.

Observe a separately labelled worker SDK input and public row before that human
ask, ordered complete notes, preserved delivered images, bounded public rows and
snapshots, and the same complete handoff reference in the oversized model and
public disclosure. The first implementation's hidden metadata fails these checks.

Use the headless/fallback procedure in neo-human-worker-batch.md. On a locked Mac,
never open a GUI browser. If headless is unavailable, do not retry another route;
render NeoWorkerBatch.test.tsx against this run's saved pages and mark browser
verification unverified. Keep observed.json, worker-handoff.json, model requests,
rendered HTML and proof/render logs. This is synthetic transport/component proof,
not real-provider reasoning or OS sandbox enforcement.
