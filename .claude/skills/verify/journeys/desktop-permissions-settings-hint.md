# Desktop permissions hint

Use a signed release bundle on a Mac with a test account. Open the desktop
permissions guide with Accessibility off. Click Open Accessibility settings.
Check that the floating panel stays beside the System Settings window without
taking keyboard focus. Drag the HyperNeo icon onto the app list and confirm
System Settings adds the app. Turn on the switch and confirm the panel closes.
Repeat in Screen Recording. Check that leaving System Settings also hides the
hint. Try a Settings window near the right screen edge and on a second display.
