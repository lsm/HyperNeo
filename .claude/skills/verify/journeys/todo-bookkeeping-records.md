# Todo PR admission and audit records

Use the shared isolated metadata-only setup in SKILL.md. The helper owns an
ephemeral daemon with external HTTP disabled and closes it in finally.

```sh
bash .claude/skills/verify/proof-run.sh \
  /absolute/fresh/evidence-directory .claude/skills/verify/todo-bookkeeping-records.ts verify
```

Through the real Neo MCP door, add and edit must refuse a duplicate live merge
check in the same ask and point to `core.evidence` for a review comment. Add and
edit must also refuse an empty check without work. A review-comment check is
accepted, and editing it with unsupported URLs records a warning and preserves
its check. The audit retains the refusals and the accepted warning across
restart. Evidence is `observed.json` and `proof.log`.
