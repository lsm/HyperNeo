# Print vector exports

All files in this directory are vector artwork. Each PDF and EPS is a single-page document sized to the corresponding logo canvas.

| Artwork | PDF | EPS |
| --- | --- | --- |
| Jade standalone mark | `mark-06-jade.pdf` | `mark-06-jade.eps` |
| Ink standalone mark | `mark-06-ink.pdf` | `mark-06-ink.eps` |
| White standalone mark | `mark-06-white.pdf` | `mark-06-white.eps` |
| Horizontal dark lockup | `lockup-06-horizontal-dark.pdf` | `lockup-06-horizontal-dark.eps` |
| Horizontal light lockup | `lockup-06-horizontal-light.pdf` | `lockup-06-horizontal-light.eps` |
| Horizontal white lockup | `lockup-06-horizontal-white.pdf` | `lockup-06-horizontal-white.eps` |
| Stacked dark lockup | `lockup-06-stacked-dark.pdf` | `lockup-06-stacked-dark.eps` |

The mark paths are resolution-independent. Lockup wordmarks remain live text and use standard Helvetica in these print exports; use the SVG masters if the Inter / Helvetica Neue system stack is required.
